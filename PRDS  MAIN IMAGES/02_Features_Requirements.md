# Mac Digital Agency — Features & Requirements

## 1. Navigation
- Minimal sticky header
- Brand/logo
- Anchor navigation
- Active section state where useful
- One strong contact CTA
- Compact animated mobile menu
- No excessive pill navigation

## 2. Hero
Required:
- Asad Chaudhary
- Website Developer
- 3+ years experience
- Since 2023
- Strong concise value proposition
- Hire Me
- View Selected Work
- Profile photograph

Forbidden:
- AI assistant
- AI popup
- Floating dashboard
- Fake browser window
- Analytics card
- Skill percentage badge
- Notification card
- Random floating widgets

The profile image must remain unobstructed.

## 3. Hero Animation
Use only subtle:
- Text reveal
- Gentle image entrance
- Small accent/line motion
- CTA hover

No constant floating, image spinning, particle effects or cursor-following widgets.

## 4. Credibility Strip
Use a restrained typographic strip such as:
`3+ YEARS EXPERIENCE / SINCE 2023 / MODERN WEB DEVELOPMENT`

Only publish verified client/project numbers.

## 5. About
Include:
- Development journey
- 3+ years experience
- Current focus
- Client-oriented approach
- Responsive implementation

## 6. Technical Expertise
Display:
- React + TypeScript — 2 years
- PHP + Database — 3 years
- HTML + CSS + JavaScript — 3 years
- Python — 1 year
- Supabase — 2 years
- Firebase — 3 years

Preferred presentation: editorial list/asymmetric grid with technology, duration and short description. Do not use fake percentage meters.

## 7. Experience
Use a minimal chronology:
- 2023 — Development journey begins
- 2023–Present — Professional web development
- Technology milestones

Do not fabricate employers.

## 8. Projects
Make projects the main proof of work.
- Large feature project
- Supporting projects
- Varied image proportions
- Strong typography
- Technology labels
- Live Demo
- GitHub/source when available

Avoid identical repetitive cards.

## 9. Services
1. Website Development
2. React Development
3. Frontend Development
4. PHP & Database Development
5. Firebase/Supabase Integration
6. Responsive Web Design

Prefer numbered editorial rows, split layouts or refined mixed compositions over six identical icon cards.

## 10. Why Work With Me
- 3+ years experience
- Responsive-first development
- Clean maintainable code
- Modern UI
- Smooth purposeful interactions
- Client-focused delivery

## 11. Testimonials
Use a refined quote-led layout. Demo testimonials are placeholders only and must be verified before launch. Never put fake reviews into structured data.

## 12. Contact CTA
Use a strong but restrained closing message and Email/WhatsApp actions. Avoid giant sales banners.

## 13. Contact
Display email, phone, WhatsApp, address and social links. No Google Map.

## 14. Contact Form
Optional frontend-only form:
- Name
- Email
- Subject
- Message
- Submit

No fake backend success. Use mailto or clearly communicate demo behavior.

## 15. Footer
Minimal brand, name, selected navigation, social links and copyright.

## 16. Accessibility
Semantic HTML, keyboard navigation, visible focus, labels, contrast, reduced motion and accessible mobile menu.

## 17. Animation Principle
**If removing an animation makes the website feel more professional, remove it.**

## 18. Production Checklist
Replace logo, profile image, project placeholders and demo testimonials. Verify statistics, URLs, contact details, CTAs, accessibility and performance.
