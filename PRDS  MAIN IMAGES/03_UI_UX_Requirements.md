# Mac Digital Agency — UI/UX Requirements

## 1. Core Art Direction
The website must look intentionally designed by a senior human UI designer.

It must not resemble:
- AI-generated portfolio
- Generic Tailwind template
- SaaS landing page
- “developer with floating cards” template

Target: premium editorial developer portfolio.

## 2. Visual Language
Base:
- Warm white / soft off-white
- Deep charcoal typography
- Restrained professional yellow
- Neutral grey

Yellow is an accent, not the whole interface. Use it for small highlights, links, selected borders and CTA emphasis.

## 3. Layout Philosophy
Use an editorial grid:
- Strong alignment
- Large margins
- Intentional whitespace
- Asymmetry where useful
- Clear vertical rhythm
- Mixed full-width and constrained sections
- Large typography balanced with small metadata

Avoid repetitive “heading + paragraph + 3 cards” sections.

## 4. Hero — Critical
Desktop:
- Left: eyebrow, name, role/value statement, paragraph, CTAs
- Right: large profile photograph

Photo treatment may use a thin border, small yellow line, simple frame or controlled crop.

**Absolutely do not add:**
- AI popups
- Chat windows
- Floating assistant
- Fake analytics panels
- Skill bubbles
- Notification cards
- AI badges
- “Available” badges
- Random UI widgets
- Cards over the face/photo

The image is the focal point.

## 5. Hero Background
Prefer clean white/off-white with a very subtle grid/line detail. Avoid giant blobs, neon gradients, particles and animated mesh.

## 6. Navigation
Minimal and premium:
- Logo
- Section links
- One emphasized CTA
- Thin divider/subtle scroll background
- Compact mobile menu

Avoid excessive pill-shaped buttons.

## 7. About
Use large statement + detailed copy + small experience metadata. Let typography carry the design.

## 8. Experience / Skills
Use a capability index/list rather than a dashboard:
- React + TypeScript — 2 years
- PHP + Database — 3 years
- HTML + CSS + JavaScript — 3 years
- Python — 1 year
- Supabase — 2 years
- Firebase — 3 years

Use fine dividers, hover row highlight and restrained yellow markers. No fake percentages.

## 9. Projects
Use one large feature project followed by supporting work. Vary layouts and image ratios. Use minimal metadata such as project number, category, technology and title.

## 10. Services
Use numbered editorial rows or alternating sections rather than six identical cards.

## 11. Testimonials
Prefer one large quote plus supporting quotes. Avoid carousel-heavy presentation unless content volume genuinely requires it.

## 12. CTA
Use typography and whitespace. Avoid giant gradients and glowing buttons.

## 13. Contact
Two-column desktop:
- Invitation/message
- Contact details

Social links should remain simple text/icon links.

## 14. Footer
Minimal and clean.

## 15. Design Tokens
Define:
`--bg`, `--surface`, `--text`, `--muted`, `--line`, `--accent`, `--accent-dark`, `--radius`, `--container`, `--section-space`

Not every element needs rounded corners.

## 16. Typography
Use a modern professional sans-serif/grotesk. Strong display heading, readable body, compact uppercase metadata. Avoid playful fonts.

## 17. Responsive
Mobile must be intentionally recomposed:
- Hero hierarchy
- Project layouts
- Skills list
- Services
- Testimonials
- Contact

No horizontal overflow.

## 18. Mobile Hero
Order:
1. Eyebrow
2. Name
3. Role/value statement
4. Paragraph
5. CTA
6. Profile image

No overlays/popups on the image.

## 19. Motion
Premium and subtle:
- 200–500ms transitions
- Ease-out entrances
- Small image transforms
- Underline animations
- Counter easing

Avoid bounce, constant floating, excessive parallax, spin and particle effects. Respect `prefers-reduced-motion`.

## 20. Visual QA
Before delivery ask:
- Does it look like an AI template?
- Are elements present only for decoration?
- Is yellow overused?
- Are there too many cards?
- Is the profile photo unobstructed?
- Are animations distracting?
- Is mobile intentionally designed?
- Is typography doing enough of the visual work?

If any answer is negative, simplify/redesign.

## Final Principle
**Professionalism comes from restraint: fewer elements, better typography, stronger spacing, better photography and intentional composition.**
